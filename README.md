# Arun Building Constructions — Website Starter

A premium black + shiny gold React/Vite website inspired by the visual direction of luxury construction/interior brands.

## Features
- Full-screen sliding hero background
- Architectural line-drawing overlay
- Black / shiny gold visual system
- Audiowide-style futuristic display typography
- Responsive mobile navigation
- SEO-ready title, description, keywords and Open Graph metadata
- Services, projects, process and contact sections
- Floating WhatsApp button
- Lazy-loaded project images
- No backend required for the starter

## Install

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Replace before launch
1. Replace the text logo in `src/main.jsx` with the company's actual logo.
2. Change phone, WhatsApp and email.
3. Replace Unsplash image URLs with Arun Building Constructions project photos.
4. Connect the contact form to your email/CRM API.
5. Add real address, service areas, company registration details and project data.
6. Add `sitemap.xml`, `robots.txt` and canonical URL once the production domain is known.
